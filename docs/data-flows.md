# Потоки данных

1. Аутентификация: Клиент -> VPN сервер -> CA сервер -> проверка сертификата
2. Трафик: Клиент <-> VPN сервер (шифрованный туннель) <-> NAT <-> интернет
3. Мониторинг: Node Exporter (9100) -> Prometheus (9090) -> Grafana (3000)
4. Бэкапы: CA/VPN серверы -> скрипты -> GCS бакет (02:00 и 02:30 UTC)
